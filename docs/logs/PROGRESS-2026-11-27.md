# Progress — 27 November 2026

## Repository restructure to the Vendo layout, documentation set created

**Why:** the project had a nested duplicate copy, three deployment patch folders, backups and a default stub in the root, controllers and views in flat folders, and no documentation folder. The owner asked for the same structure as the Vendo project (role-grouped code, a separate `docs/` folder with progress logs, specs and `AGENTS.md`).

### Code moves (no behavior change intended)

| From | To |
|---|---|
| `Controllers/AuthController`, `PasswordResetController` | `Controllers/Auth/` |
| `Controllers/BranchController`, `CashierController`, `SettingsController`, `StatisticsController` | `Controllers/Admin/` |
| `Controllers/HomeController`, `OrderController`, `ServedController` | `Controllers/Cashier/` |
| `Controllers/ProfileController` | unchanged (shared by both roles) |
| `Models/Order`, `OrderItem` | `Models/Sales/` |
| `Models/MenuItem` | `Models/Catalog/` |
| `Models/ReceiptSetting` | `Models/Settings/` |
| `views/pages/{homepage,orders,served}` | `views/cashier/` |
| `views/pages/{statistics,settings}` | `views/admin/` |

| `views/pages/profile`, `views/pos-shell` | `views/shared/profile`, `views/shared/pos-shell` |

Updated to match: controller namespaces (plus an import of the base `Controller`), model namespaces and every `use` of them (controllers, `DatabaseSeeder`), the controller imports in `routes/web.php`, and all `view()` names. Route names, URLs, table names and `public/` paths are unchanged.

### Removed (all remain in git history)

- `deploy-laravel/`, `deploy-public/`, `deploy-stats-fix/` — patch bundles from commit `f5cf396`. Their files are identical to the root versions, except `deploy-laravel`'s older `statistics.blade.php`.
- `composer.json.laravel13-backup`, `composer.lock.laravel13-backup` — the Laravel 13 files from before commit `6c29c14`.
- `resources/views/welcome.blade.php` — the unused Laravel default page (no route used it).

### Documentation added

`docs/README.md`, `architecture.md`, `schema.md`, `security.md`, `testing.md`, `setup.md`, `domain-feature-status.md`, `feature-implementation-guide.md`, `order-flow-decisions.md`, `future-plan.md`, `domains/{Admin,Cashier}.md`, and 11 feature specs under `docs/features/`. `AGENTS.md` was rewritten in the Vendo format; its detailed order and business rules moved into `docs/order-flow-decisions.md`. `README.md` now describes this project instead of stock Laravel.

### Documentation corrected against the code

- Business day starts at **3:00 PM** Manila time (`Pos::bizDate`), not 5:00 AM as the old `AGENTS.md` said.
- Order types are `dine-in`, `take-out`, `delivery`, `pick-up`, not just two.
- The framework is Laravel **12** (lock v12.70.0), not 13.
- No GCash reference number is ever stored (the columns are always written as `null`).

### Known gaps found (not fixed)

Serve/void have no status guard; the merged statistics report is open to any admin; receipt settings are global; password reset reveals registered emails; disabled accounts can still sign in. Details in [security](../security.md) and [future plan](../future-plan.md).

## Uploaded files no longer tracked by git

**Why:** avatars and menu photos uploaded through the app were committed to the repository (`public/assets/images/avatars/`, `public/assets/images/menu/`). That is user data, not source, and it would be pushed to GitHub with every clone.

### Changed

- `.gitignore` now ignores everything in `public/assets/images/avatars/` (except `.gitkeep`), `menu/` and `settings/`.
- `docs/architecture.md` has a new **Uploads** section describing where uploads live and why they stay in `public/`.

### Not changed

No controller, view, route or stored path changed. Uploads still go to `public/assets/images/…`. Moving them to `storage/app/public` was considered and left alone: it would change three upload methods, every image display and the stored database paths, and needs a `storage:link` symlink that shared hosting and Windows often do not allow.

### Owner action (git only, files stay on disk)

Stop tracking the files already committed: `git rm --cached` on the avatar and menu photo files. They remain in git history.

### Verification

Static only. Nothing was executed.

## StatisticsController split into three focused controllers

**Why:** `Admin/StatisticsController.php` was 666 lines and mixed three jobs: the Statistics page, the live petty-cash/expense forms, and the Excel JSON feed.

### Code moves (no behavior change intended)

| Method | From | To |
|---|---|---|
| `index` | `Admin/StatisticsController` | unchanged (now about 320 lines) |
| `saveDailyCash`, `addExpense`, `updateExpense` | `Admin/StatisticsController` | `Admin/DailyFinanceController` |
| `report` | `Admin/StatisticsController` | `Admin/StatisticsReportController` |

The method bodies were moved verbatim. `updateExpense` was indented one level too deep and was re-indented to match the rest. `routes/web.php` points the four routes at the new controllers. URLs, route names (`statistics`, `statistics.report`, `statistics.daily-cash`, `statistics.expenses.store`, `statistics.expenses.update`), the admin middleware group, views and JavaScript are unchanged.
